Project Statement

Project Title

Online Quiz Management System

Problem Statement

Traditional quiz management can require manual question management, answer checking, score calculation, and result recording. This can be time-consuming and may lead to errors.

The Online Quiz Management System provides a simple Java-based solution for managing quizzes. It allows administrators to manage quiz questions and allows students to register, log in, attempt quizzes, and view their results.

Scope

The project covers:

- Student registration and login.
- Administrator login.
- Quiz question management.
- Adding, viewing, searching, updating, and deleting questions.
- Online quiz participation through a console interface.
- Automatic answer checking.
- Automatic score and percentage calculation.
- Result storage and retrieval.
- Input validation and error handling.

Target Users

Students

Students can create an account, log in, attempt available quizzes, and view their results.

Administrators

Administrators can manage the quiz question bank and maintain quiz content.

High-Level Features

1. Student Registration
2. Student Login
3. Admin Login
4. Question Management
5. Quiz Attempt
6. Automatic Score Calculation
7. Result Management
8. Input Validation
9. File-Based Data Storage
10. Error Handling

Technology

- Java
- Object-Oriented Programming
- File Handling
- Collections
- Exception Handling
- Visual Studio Code
- Git and GitHub

Expected Outcome

The system provides a functional console-based quiz platform where administrators can manage questions and students can successfully attempt quizzes and receive automatically calculated results.
